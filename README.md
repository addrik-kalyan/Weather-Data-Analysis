# Weather Prediction Model

A machine learning project that predicts weather conditions using Python and NumPy.

## Overview
This project demonstrates how historical weather data can be used to build a predictive model for forecasting temperature and other atmospheric conditions.

## Technologies Used
- Python
- NumPy
- Matplotlib
- Scikit-learn

## Dataset
The model is trained on historical weather data containing features such as temperature, humidity, and other weather-related attributes.

## Workflow
1. Load the weather dataset
2. Preprocess and normalize the data
3. Split data into training and testing sets
4. Train a machine learning model
5. Evaluate prediction accuracy
6. Forecast weather conditions

## Results
The model predicts weather values based on historical patterns and demonstrates the fundamentals of regression and data analysis.

## Project Structure
- `weather_np.ipynb` – Jupyter notebook containing the complete implementation
- `README.md` – Project documentation
